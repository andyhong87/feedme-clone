# URL to Markdown

웹 페이지 URL을 붙여 넣으면 본문을 Markdown으로 추출하고, 복사·다운로드하거나 ChatGPT·Claude로 바로 넘길 수 있는 서비스입니다.

## 사용자 결과

- URL 하나를 붙여 넣으면 해당 페이지의 본문이 Markdown으로 바뀌어 화면에 렌더링됩니다.
- 결과 위에 페이지 제목과 저자가 표시됩니다.
- 사용자는 Markdown을 복사하거나 `.md` 파일로 받거나, 프롬프트와 함께 ChatGPT·Claude에서 바로 대화를 시작할 수 있습니다.

## 승인된 화면

[prototype.html](prototype.html)이 승인된 화면 구성, 상태, 문구, 반응형 배치를 정합니다. 이 스펙은 동작과 수용 기준을 정하고, 화면의 세부 구성(간격, 컴포넌트 배치, 문구)은 프로토타입을 따릅니다. 프로토타입은 참고용이며 제품 코드가 아닙니다. 프로토타입의 가짜 변환 규칙(URL에 따라 결과가 갈리는 부분)과 ChatGPT·Claude 새 탭을 열지 않는 동작은 시연용이므로 구현 대상이 아닙니다.

화면은 URL 변환 하나이고, 프로토타입의 상태 선택기에 다음 상태가 있습니다: Default, Loading, Result, Long result, Invalid URL, Fetch failed, Not HTML, Empty content, Copy failed.

## 범위

### 포함

1. **입력**: URL 입력란, 입력란 안쪽 오른쪽의 아이콘 버튼 하나(입력 중에는 변환 화살표, 변환이 끝나면 지우기 X)
2. **변환**: 본문을 Markdown으로 추출합니다. 추출에는 defuddle 라이브러리를 반드시 사용합니다.
3. **결과 확인**: 제목·저자 헤더와 렌더링된 Markdown
4. **내보내기**: 복사하기, `.md` 다운로드, ChatGPT로 열기, Claude로 열기
5. **프롬프트**: 프리셋 "요약해줘", "한국어로 번역해줘", "쉽게 설명해줘"와 "직접 입력"
6. **다크모드 토글**

### 제외

- 계정, 로그인, 변환 기록 저장, 즐겨찾기
- 직접 입력한 프롬프트의 저장 (1회용)
- 여러 URL 일괄 변환, 로그인이 필요한 페이지, 브라우저 렌더링이 필요한 페이지
- 사용자 정의 프리셋 추가

## 동작 계약

### 입력과 변환

- 별도의 "변환" 텍스트 버튼은 없습니다. 입력란 안쪽 오른쪽의 아이콘 버튼 하나가 상태에 따라 바뀝니다.
  - 입력 중(처음 상태 포함): 변환 화살표입니다. 누르거나 엔터를 치면 변환합니다. 화살표는 스크린리더용 이름("변환")을 가집니다.
  - 변환 중: 같은 자리에서 스피너가 돌고, 입력과 버튼이 잠겨 중복 제출을 막습니다. 결과 영역에는 로딩 표시(Skeleton)가 나옵니다.
  - 변환이 끝난 뒤(결과든 오류든): 같은 자리가 지우기 X로 바뀝니다.
  - 변환이 끝난 뒤 URL을 고치면 X가 다시 화살표로 돌아가 바로 재변환할 수 있습니다.
- 빈 입력이거나 http(s) URL이 아니면 변환하지 않고, 입력란 아래에 입력 오류를 알립니다. 이때는 화살표가 그대로 남습니다.
- 지우기 X는 URL, 결과, 오류, 선택한 프롬프트와 직접 입력 내용을 모두 초기화하고 입력란에 커서를 돌려줍니다.
- 처음 상태에서는 변환할 주소를 입력하라는 안내(Empty)를 보여줍니다.

### 결과

- 헤더에는 제목과 저자를 보여줍니다. 저자가 없으면 저자 자리를 비웁니다.
- 본문은 Markdown 원문이 아니라 렌더링된 형태로 보여줍니다. 본문 첫 줄의 제목은 헤더와 중복되므로 본문에 다시 넣지 않습니다.
- 넓은 화면에서는 본문을 왼쪽에, 내보내기 패널을 오른쪽에 두고, 패널은 스크롤을 따라옵니다. 좁은 화면에서는 제목·저자, 내보내기, 본문 순서로 쌓아 긴 문서에서도 내보내기가 바로 보이게 합니다.
- 헤더 오른쪽 위의 다크모드 토글이 화면 전체에 적용됩니다.

### 내보내기

- **복사하기**와 **.md 다운로드**는 프롬프트와 무관하게 변환된 Markdown만 내보냅니다. 다운로드 파일명은 페이지 제목에서 만듭니다.
- **ChatGPT·Claude로 열기**만 프롬프트를 앞에 붙입니다. 프롬프트를 고르지 않으면 본문만 넘깁니다. 기본값은 프롬프트 없음입니다.
- 넘길 전체 텍스트(프롬프트 + Markdown)가 짧아 URL에 담길 때는 해당 서비스의 새 탭을 열면서 텍스트를 미리 채웁니다.
- 길어서 URL에 담을 수 없을 때는 전체 텍스트를 클립보드에 복사하고, 해당 서비스의 새 탭을 연 뒤, 화면에 붙여넣기 안내를 보여줍니다.
- 클립보드 복사에 실패하면 실패했음을 알리고 수동 복사 방법(복사하기 버튼)을 안내합니다.

### 프롬프트

- 프리셋 세 개와 "직접 입력"이 나란히 선택지로 놓이고, 하나만 고를 수 있습니다. 고른 항목을 다시 누르면 선택이 풀려 프롬프트 없음으로 돌아갑니다.
- "직접 입력"을 고를 때만 텍스트 입력란이 나타납니다. 입력 내용은 저장하지 않으며 새로고침하면 사라집니다.
- "직접 입력"을 골랐지만 내용이 비어 있으면 프롬프트 없이 본문만 넘깁니다.

### 실패 상태

변환이 실패하면 이유를 구분해 알리고 입력은 그대로 둡니다.

- 페이지를 가져오지 못함(네트워크 오류, 시간 초과, 접근 차단·4xx/5xx)
- HTML 페이지가 아님
- 본문을 추출했지만 내용이 사실상 비어 있음(차단 안내 문구만 반환되는 경우 포함)

## 제약과 근거

- **서버에서 가져오고 변환합니다.** defuddle은 URL을 직접 가져오지 않고 HTML과 DOM 구현체를 받습니다. 브라우저에서 임의 사이트를 가져오면 CORS로 막히므로 서버 쪽 처리가 필요합니다.
- **DOM 구현체는 linkedom을 전제로 합니다.** scratch 디렉터리에서 jsdom 30과 defuddle을 함께 쓰면 `Selector exceeds maximum allowed length of 2048`로 변환이 실패했고, linkedom에서는 개인 블로그, Wikipedia, Hacker News가 정상 변환됐습니다. 이 프로젝트의 devDependency인 jsdom은 테스트용이며 변환에 쓰지 않습니다.
- UI는 [ui-composition](../../decisions/ui-composition.md) 결정을 따릅니다. 일반 UI는 shadcn component와 semantic token으로 구성하고, loading·empty·error·success·disabled 상태를 정상 화면과 함께 설계하며, 좁은 화면에서는 위계를 유지한 채 쌓습니다.
- 제품 전체 전제를 담은 `PRODUCT.md`는 아직 없어 적용할 앱 수준 제약이 없습니다.

## 가정 (덮어쓸 수 있음)

- ChatGPT와 Claude는 각각 쿼리 파라미터로 입력창을 미리 채우는 새 대화 주소를 지원합니다. 이는 로그인 상태가 필요해 확인하지 못했습니다.
- "짧다/길다"의 경계는 인코딩된 URL 전체 길이로 판단합니다. 한글은 인코딩 시 길이가 크게 늘기 때문에 글자 수가 아니라 인코딩 후 길이를 기준으로 하고, 구체적인 한도는 구현 중 보수적으로 정합니다.
- 다크모드는 처음 방문 시 시스템 설정을 따르고, 토글로 바꾼 선택은 이 브라우저에서 유지합니다.
- 변환 대상은 서버가 일반 HTTP 요청으로 받을 수 있는 공개 페이지입니다.
- 저자 정보는 defuddle이 반환하는 값을 그대로 씁니다. Hacker News처럼 저자가 비는 페이지가 있습니다.
- 변환이 끝난 시점에 화살표가 X로 바뀌는 해석은 사용자가 확인했습니다. 글자를 입력하는 즉시 X를 보여 주는 방식은 채택하지 않았습니다.
- 클립보드 복사에 실패하면(Copy failed) 복사하기 버튼은 실패 토스트를, 긴 문서의 ChatGPT·Claude 열기는 "새 탭을 열지 않았다"는 경고를 보여줍니다. 이 경우 새 탭은 열지 않습니다.
- 변환 결과를 보는 동안 선택한 프롬프트는 유지되고, 지우기 X를 눌렀을 때만 초기화됩니다.

## 건드리지 않는 영역

- 기존 `app/page.test.tsx`의 기본 템플릿 검증은 이 작업에서 새 화면에 맞게 교체되는 대상입니다. 별도 보호 대상은 없습니다.
- `docs/decisions/ui-composition.md`는 이 작업에서 바꾸지 않습니다.

## 보류와 위험

- **ChatGPT·Claude URL 파라미터 동작**: 쿼리로 채우는 방식이 바뀌거나 길이 한도가 예상과 다르면 "짧은 경우" 경로가 줄어듭니다. 긴 경우의 클립보드 경로가 항상 대체 수단이 됩니다.
- **한글 문서는 거의 클립보드 경로로 갑니다**: 프로토타입에서 한글 1,347자가 인코딩 후 7,777자였습니다. 한도를 8,000자 안팎으로 잡으면 한글 문서는 프롬프트를 붙이는 순간 대부분 한도를 넘으므로, URL로 채우는 경로는 사실상 짧은 영문 문서에서만 쓰입니다. 동작은 이 스펙대로 두되, 한도나 방식은 구현 뒤 실제 문서로 다시 판단합니다.
- **JS 렌더링·봇 차단 페이지**: 일부 사이트(예: nytimes.com은 403)는 본문을 얻지 못하고 실패 상태로 끝납니다. 이 범위에서는 해결하지 않습니다.
- **SSRF·남용 방어**: 서버가 임의 URL을 가져오는 구조이지만, 이 스펙은 강의용 템플릿 범위에 맞춰 별도 하드닝을 요구하지 않습니다.

## 수용 기준

1. 공개 블로그 글 URL을 붙여 넣고 변환하면 제목, 저자, 렌더링된 Markdown이 순서대로 나타난다.
2. 변환이 끝나면 입력란 안쪽의 화살표가 같은 자리의 X로 바뀌고, X를 누르면 입력, 결과, 오류, 선택한 프롬프트, 직접 입력한 프롬프트가 모두 비워지며 화살표가 돌아온다. 결과가 나온 뒤 URL을 고치면 X가 화살표로 돌아온다.
3. 복사하기를 누르면 클립보드에는 프롬프트 없이 Markdown만 들어 있다.
4. .md 다운로드는 제목에서 만든 파일명의 Markdown 파일을 내려받는다.
5. 프리셋을 고르고 짧은 문서를 ChatGPT 또는 Claude로 열면, 프롬프트가 본문 앞에 붙은 채로 해당 서비스의 새 탭이 열린다.
6. 긴 문서를 열면 프롬프트 + 본문이 클립보드에 복사되고, 새 탭이 열리며, 붙여넣기 안내가 화면에 보인다.
7. "직접 입력"을 선택했을 때만 텍스트 입력란이 보이고, 새로고침 뒤에는 입력 내용이 남지 않는다.
8. 잘못된 URL, 접근 차단 페이지, HTML이 아닌 URL, 내용이 비는 페이지는 각각 구분된 오류 메시지를 보여주고 입력은 유지된다.
9. 다크모드 토글이 화면 전체에 적용되고, 다시 열어도 선택이 유지된다.
10. 변환 중에는 화살표 자리에 스피너가 돌고 결과 영역에 로딩 표시가 나오며, 입력과 버튼이 잠겨 중복 제출이 되지 않는다.
11. defuddle로 변환하고, 좁은 화면(약 400px)에서도 모든 작업과 결과가 가려지지 않는다.
12. 좁은 화면에서는 제목·저자, 내보내기, 본문 순서로 쌓이고 가로 스크롤이 생기지 않는다. 넓은 화면에서는 본문 오른쪽에 내보내기 패널이 따라온다.
13. 클립보드 복사가 실패하면 복사하기는 실패 토스트를, 긴 문서의 ChatGPT·Claude 열기는 새 탭을 열지 않았다는 경고를 보여준다.
14. 프롬프트 선택지는 하나만 선택되고, 고른 항목을 다시 누르면 선택이 풀려 본문만 넘어간다.
